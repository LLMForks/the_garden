# The Garden — бета

Cozy-кооператив про фермерство: у вас с друзьями не по своей ферме, а **один общий остров на всех**.
Сажайте, поливайте, собирайте урожай, готовьте блюда и украшайте сад — прогресс копится у всей компании.
Растения не вянут, ничего не сгорает без вас, игра никуда не торопит.

Это **офлайн-бета** на [Bevy](https://bevyengine.org) для проверки геймфила. Кооп в ней изображают
NPC-друзья (Мила — садовница, Тёма — повар, Ксю — декоратор): они заглядывают на остров и уплывают
(дроп-ин/дроп-аут), ведут свои личные грядки, поливают чужие, готовят из излишков и дарят украшения.

## Запуск (Linux x86_64: Debian 13 / KDE / Wayland и др.)

```sh
tar xzf the_garden-linux-x86_64.tar.gz
cd the_garden
./the_garden
```

Бинарник самодостаточный: все ассеты (графика, звук, шрифт) вшиты внутрь. Нативно работает под Wayland
(и под X11/XWayland). Нужны стандартные библиотеки рабочего стола — на Debian 13 с KDE они уже стоят:

```sh
sudo apt install libvulkan1 mesa-vulkan-drivers libasound2t64 libudev1 libwayland-client0 libxkbcommon0 libxkbcommon-x11-0
```

Если видеодрайвер не поддерживает Vulkan, можно попробовать OpenGL: `WGPU_BACKEND=gl ./the_garden`.

## Windows

Распаковать `the_garden-windows-x64.zip` и запустить `the_garden.exe` — это один файл, ничего ставить не нужно
(Windows 10/11 x64). Файл не подписан, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить в любом случае».
Сохранение на Windows: `%APPDATA%\the_garden\save.ron`.

## Сохранения и обновление

Прогресс хранится **отдельно от игры**: `~/.local/share/the_garden/save.ron`
(если задан `XDG_DATA_HOME` — `$XDG_DATA_HOME/the_garden/save.ron`).
Автосейв каждые 20 с, плюс при закрытии окна и при «Сохранить и выйти».

Обновление без потери прогресса:

1. В игре: Esc → «Сохранить и выйти» (или просто закрыть окно).
2. По желанию сделать копию: `cp ~/.local/share/the_garden/save.ron ~/save-backup.ron`.
3. Распаковать новый архив поверх старой папки (или в любую другую) и запустить `./the_garden`.

Новые версии читают старые сохранения. **Не запускайте с `--fresh`** — этот флаг удаляет сохранение и начинает
новый остров. Свой файл сохранения можно указать через `--save путь/к/save.ron`.

## Управление

| Клавиша | Действие |
| --- | --- |
| WASD / стрелки | ходить (Shift — быстрее) |
| ЛКМ / Пробел | действие инструментом (можно зажать и «рисовать» грядки) |
| ПКМ | убрать украшение или вернуть траву на пустую грядку |
| 1–7 / колесо | слот: мотыга, лейка, 4 вида семян, украшение |
| R | сменить украшение в слоте 7 |
| E | кухня, лавка, ящик продажи, колодец, доска, друзья, питомцы |
| Tab | общий склад |
| + / − | приближение камеры |
| H | управление · Esc — пауза/настройки |

## Что есть в бете

- **Остров** с личными зонами (твоя, Милы, Тёмы, Ксю — строить там может только хозяин, поливать — все)
  и общей зоной с кухней, лавкой, ящиком продажи, складом, колодцем и доской целей.
- **4 культуры**: пшеница, морковь, капуста, картофель. Вскопать → посадить → полить (×2 к росту) → собрать.
  Ничего не вянет; сухая грядка просто растёт медленнее. Урожай и семена возвращаются на общий склад.
- **Кулинария** на общей кухне: хлеб, салат, пюре, рагу, морковный пирог, пирог с капустой.
- **Экономика**: продажа урожая/блюд в общую казну, покупка семян и украшений.
- **Прогрессия**: общий уровень острова (открывает культуры, рецепты, декор) + личные навыки
  «Садовник», «Повар», «Декоратор». Цепочка общих целей острова.
- **Сезоны** (по 3 игровых дня): бонусы к разным культурам, зимой блюда дают больше опыта,
  сезонный декор возвращается каждый год. Погода: дождь сам поливает грядки, зимой идёт снег.
- **Смена дня и ночи**, фонари светятся ночью, светлячки и бабочки.
- **Питомцы**: кошка и лисёнок приходят, когда сад становится уютным (уют = украшения). Их можно гладить.
- **Офлайн-прогресс**: вернувшись, увидишь «Пока тебя не было…» — урожай подрос, Мила полила грядки,
  друзья принесли овощи на склад.
- **Геймфил**: инерция движения, squash & stretch, частицы земли/воды/урожая, урожай подлетает к персонажу,
  нарастающий по высоте звук сбора подряд, лёгкая тряска камеры, покачивание растений на ветру и когда
  проходишь сквозь них, мерцающие готовые грядки, тосты и баннер уровня с конфетти.

## Сборка из исходников

```sh
# Debian/Ubuntu
sudo apt install build-essential pkg-config libasound2-dev libudev-dev libwayland-dev libxkbcommon-dev
cargo build --release
./target/release/the_garden
```

Ассеты генерируются процедурно скриптами (Python 3 + Pillow + numpy) и уже лежат в `assets/`:

```sh
python3 tools/gen_art.py     # пиксель-арт, карта острова
python3 tools/gen_audio.py   # звуки и музыка (синтез)
```

Шрифт — [Nunito](https://github.com/googlefonts/nunito) (SIL OFL 1.1, см. `assets/fonts/`).

## Браузерная версия

```sh
rustup target add wasm32-unknown-unknown
cargo install wasm-bindgen-cli --version <версия wasm-bindgen из Cargo.lock>
./tools/build_web.sh            # -> dist/web (сайт) и dist/the_garden-web.zip (для itch.io)
python3 -m http.server -d dist/web 8000   # открыть http://localhost:8000
```

В браузере прогресс хранится в `localStorage`. Параметры передаются через адрес: `?fresh`, `?autotest`.

## CI/CD (GitHub Actions)

- **`.github/workflows/ci.yml`** — на каждый push и PR: юнит-тесты, бот `--autotest` под Xvfb
  (скриншоты в артефактах) и проверка, что браузерная сборка компилируется.
- **`.github/workflows/release.yml`**:
  - push в `main` → собрать веб-версию, проверить её в headless Chromium и выложить на **GitHub Pages**;
  - тег `v*` (например `git tag v0.2.0-beta && git push --tags`) или ручной запуск (Actions → Release → Run workflow) →
    Linux, Windows и веб, **GitHub Release** с архивами (только для тегов), **Pages** и **itch.io**.

Один раз настроить в репозитории:

1. **GitHub Pages:** Settings → Pages → Build and deployment → Source: **GitHub Actions**.
2. **itch.io:** создать страницу игры на itch.io (тип «HTML» — чтобы можно было играть в браузере), затем
   Settings → Secrets and variables → Actions:
   - секрет `BUTLER_API_KEY` — ключ с https://itch.io/user/settings/api-keys;
   - переменная `ITCH_GAME` — `<ник-на-itch>/<адрес-игры>`, например `petr/the-garden`.

   Workflow выкладывает три канала: `linux`, `windows`, `html5`. После первой загрузки на странице игры на itch
   отметить файл `html5` галочкой «This file will be played in the browser» и указать размер окна, например 1280×720.
   Если секрета нет, шаг itch.io пропускается с предупреждением.
